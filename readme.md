# Burse .NET & Angular

## How to run

### .NET backend

```sh
dotnet run --project Presentation --launch-profile http
```

Open [Scalar](http://localhost:5243/scalar) or [Swagger](http://localhost:5243/swagger) in your browser.

### Angular frontend

```sh
cd Frontend
npm ci
npm start
```
