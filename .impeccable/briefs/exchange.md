# Exchange workspace

Mode: Operate.

Approved scope and visual authority: the user requested implementation of GUI-SPEC.md. Build code-first; app screens prioritize precision and familiar controls. No prior frontend exists.

Direction contract: warm off-white ground, white working surfaces, dark ink, deep blue action accent; one system sans family, tabular right-aligned numeric data, fine table dividers, and generous separation between task groups. The signature layout pairs an order book with an inline order ticket. Compact navigation carries the active trader. No invented charts, ticker symbols, currency, or market-change claims.

Desktop: wide data table, two-column stock workspace. Mobile: stacked task sections, wrapping navigation, labelled scroll regions for wide data. Stable loading geometry, clear stale/error/empty states, visible focus, reduced motion, and color-independent buy/sell semantics.

Required validation: desktop and mobile captures, real two-trader flow, keyboard and accessibility checks, build and focused checks for identity, orders, reservations, matching, cancellation, and portfolio valuation.
